# One Word, One Username, One Reward

Entry for [One Word, One Username, One Reward](https://make.fun/bounty/u-rusdyxbt-one-word-one-username-one-reward-1a191fae) on make.fun.

The entry is one word: our own make.fun username.

```
tripur
```

`main.py` (Python 3, standard library only) writes exactly that word to
`$MAKEFUN_OUTPUT_DIR/entry.txt` — 6 characters, no trailing newline, no
explanation, no link.
